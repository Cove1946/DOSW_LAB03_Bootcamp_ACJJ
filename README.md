# a. ¿Qué es un pull request en GitHub?

Un pull request es una solicitud formal para que los cambios realizadas en una rama
de un repositorio sean revisados y aprovados por algun otro integrante del proyecto
para que asi sean integrados en la rama principal o en la que se este trabajando.

**El Pull request nos permite:**

Revisar los cambios realizados en el codigo

Discutir modificaciones mediante comentarios

Ejecutar pruebas automáticas, pero estas deben estar configuradas

Aprobar o rechazar los cambios antes de integrarlos


# b. ¿Cómo se crea un Pull Request en GitHub?

Para crear un Pull Request GitHub nos recomienda seguir los siguientes pasos

1. Crear una nueva rama desde la rama principal

2. Realizar los cambios necesarios en el proyecto

3. Confirmar los cambios (commit)

4. Subir la rama al repositorio remoto usando git push

5. Ir al repositorio en GitHub

6. Hacer clic en el boton "Compare & pull request"

7. Agregar un título y una descripción explicando los cambios realizados

8. Hacer clic en "Create pull request".


Despues de realizar estos pasos el Pull Request quedara abierto para la revision
por parte de los integrantes del equipo del trabajo

# c. ¿Cómo se aprueba un pull request en GitHub?
Para aprobar un Pull Request GitHub nos recomienda seguir los siguientes pasos:

1. Ingresar al Pull Request abierto

2. Revisar los cambios en la pestaña "Files changed"

3. Agregar comentarios si es necesario

4. Hacer clic en "Review changes"

5. Seleccionar la opción "Approve"

6. Confirmar la revision

Una vez aprovado y si cumple con la configuracion del repositorio,
se podra acceder al "Merge pull request" para integrar los cambios en la rama principal
